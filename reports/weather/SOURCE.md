# Weather source
- Open-Meteo archive API (ERA5 reanalysis), retrieved 2026-09-06.
- Endpoint: https://archive-api.open-meteo.com/v1/archive, hourly, UTC.
- 10 airport grid points (coords in download log), 2025-01-01..2026-07-31.
- Vars: temperature_2m, dew_point_2m, precipitation, snowfall, wind_speed_10m, wind_gusts_10m, cloud_cover.
- License: open data (ECMWF ERA5 via Open-Meteo); documented for prize reproducibility.
